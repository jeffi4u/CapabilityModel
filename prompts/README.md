# Prompt Library

This directory serves as the **Prompt Library** for the Capability Map project. 

It contains rules, context files, and structured prompts that you can reference when asking the AI to make changes. Keeping these rules here ensures the AI has a consistent, version-controlled source of truth regarding your business logic and design rules.

## Available Prompts
- [`business_capability_rules.md`](./business_capability_rules.md) - Defines the rules and constraints regarding Business Capabilities.
- [`change_management_validation.md`](./change_management_validation.md) - Outlines criteria and procedures for validating proposed additions or modifications to the Capability Map.
